## หมายเหตุ

- **Firebase vs Supabase** ทำหน้าที่เดียวกัน (ชั้น 3)
  Firebase ข้อมูลเป็นเอกสาร ใช้เป็นแล้ว · Supabase ข้อมูลเป็นตาราง ใช้ SQL ได้ → ใช้ Firebase ต่อ
- **n8n** = ต่อแอปเข้าหากันแบบลากกล่อง ทำงานเดียวกับ Apps Script
  ตั้งเครื่องเองฟรีแต่ต้องมีเซิร์ฟเวอร์ · n8n Cloud ประมาณ €20+/เดือน · ตอนนี้ Apps Script ทำแทนได้ ฟรี
- **ไม่ต้องมีเครื่องเซิร์ฟเวอร์** ทั้งเว็บนำเสนอและเว็บที่มีฟอร์ม · คนเข้าเยอะได้เพราะ Cloudflare กระจายเว็บไปหลายเครื่องทั่วโลก (CDN)
- **GitHub Pages ไม่ให้ใช้เป็นเว็บธุรกิจ** → เว็บบริษัทใช้ Cloudflare Pages

## เว็บบริษัท 2 แบบ

1. **แบบนำเสนอ** (คนดูอย่างเดียว) — ชั้น 1 + 2 + 10 · Cloudflare ตัวเดียวพอ · ประมาณ 500 บาท/ปี (ค่าโดเมน .com)
   รับอีเมล `ติดต่อ@โดเมน` ส่งต่อเข้า Gmail ได้ฟรี (Cloudflare Email Routing)
2. **แบบมีกรอกข้อมูล** — แบบ 1 + ชั้น 3 (+7 ถ้าต้องแจ้งเตือน) · ต้องมีหน้านโยบายความเป็นส่วนตัว (PDPA) ถ้าเก็บชื่อ/เบอร์โทร
