# ผังประตูกรุงเทพ — ข้อมูลประกอบ

- `sg-zones.json` — กรอบที่เจ้าของวาดเองใน `prototypes/tools/zone-draw.html?b=sg` (28 ต.ค. 69 · 36 กรอบ) · พิกัด = พิกเซลบนภาพดาวเทียม 1241×831
- `sg-zones-raw.json` — สถานะดิบของเครื่องมือ (ใช้กู้คืนลงเบราว์เซอร์ได้)
- ชื่อในกรอบคือคำของเจ้าของ — ใช้ชื่อตามนี้ ชนิด "อื่นๆ" ให้อ่านความหมายจากชื่อ
- ยังไม่มีมาตราส่วน (ยังไม่ได้วัดระยะจริง)

## กติกาที่จอด (เจ้าของบอก 28 ต.ค. 69)

- **ลานจอดผู้ค้า/พ่อค้า** = ลูกค้าจอดได้ด้วย (จอดได้ทุกที่)
- **ลานจอดลูกค้า** = พ่อค้า/ผู้ค้า **ห้ามจอด**

## ข้อสังเกตจากชื่อกรอบ

- "อาคารกานต์มณี" — กรอบคือพื้นที่ทั้งหมดของประตูกรุงเทพ ตัวตึกจริงเล็กกว่ากรอบ
- "ที่เดียวกับตึกกานต์มณี" (หลังคาสีฟ้า) = ส่วนหนึ่งของตึกเดียวกัน
- รางรถไฟฟ้าลอยฟ้า — เจ้าของลบกรอบออก (ไม่ใช่ถนนพื้น)
