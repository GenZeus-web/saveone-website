## อารมณ์

**ตลาดตอนเย็น–กลางคืน สีสด อ่านง่าย** — พื้นม่วงคราม หัวข้อขาวหนา ราคาเหลือง ปุ่มเขียว GO ป้ายโซนสีตามหมุดบนผัง
เป็นมิตร ไม่เรียบหรู · ผู้ค้า/ลูกค้า/ผู้ใหญ่ เปิดดูแล้วไม่งง

**กฎข้อแรก:** หัวข้อ / เนื้อความ / ราคา / ป้ายโซน / ปุ่ม **ต้องคนละสีเสมอ**
(เจ้าของปัดตกแบบก่อนๆ เพราะ "ตัวหนังสือก็สีเหมือนกันหมด แยกไม่ออก ไม่อยากอ่าน") · ห้ามกลับไปโทนเทา-ครีมเรียบหรู ตัวบาง

## 2 ธีม: มืด + สว่าง

- มีปุ่มสลับที่แถบบน · ครั้งแรกเลือกตามเครื่อง (`prefers-color-scheme`) · จำค่าที่เลือกไว้ใน localStorage
- **ความหมายสีเหมือนกันทั้งสองธีม** — ธีมสว่างแค่ปรับสีให้เข้มขึ้นเพื่อให้อ่านบนพื้นขาวได้

## ฟอนต์

**Prompt** ตัวเดียวทั้งเว็บ (Google Fonts) · 400 เนื้อความ · 500 เมนู/ชิป · 600 ปุ่ม/ป้าย/หัวการ์ด · 700 หัวข้อ/ราคา
**ห้ามใช้ตัวบาง 200–300**

| ระดับ | ขนาด |
|---|---|
| หัวหน้าแรก | `clamp(40px, 6vw, 72px)` |
| หัวหน้าย่อย | `clamp(32px, 4.6vw, 52px)` |
| หัวข้อส่วน | `clamp(26px, 3.4vw, 38px)` |
| หัวข้อย่อย | `clamp(22px, 2.6vw, 28px)` |
| เนื้อความ | 16px · บรรทัด 1.65 · คำนำ 17px |
| ราคา | 32px หนา |

ภาษาไทย **ห้ามตัดบรรทัดกลางคำหรือวลีสั้น** — ห่อด้วย `.w` (หรือ `.nb` ไม่ให้ขึ้นบรรทัดใหม่เลย)

## รูปทรง

- มุมมนมาก: ปุ่ม/ชิป/แท็บ = แคปซูล · การ์ด 22px · รูปหัวหน้า/ผัง 26px · กล่องไอคอน 14px
- ขอบบาง 1px · ไอคอน **วาดเอง** เป็นเส้น (SVG) — **ไม่ใช้อีโมจิ**
- เนื้อหากว้างสุด 1180px · ขอบข้าง 32 → 20 (แท็บเล็ต) → 16px (มือถือ)

## โลโก้และรถ

- โลโก้ต้นฉบับ `brand/ref-logos/` (logo.png · logo-wordmark.svg) · บนหน้าเว็บ: ตัวอักษรสีหัวข้อ + "GO" เขียว (ธีมสว่างใช้เขียวเข้ม `#3f9a12`)
- โลโก้ 3D: **ลุค A ครีม** (กลางวัน) + **ลุค B ป้ายไฟกลางคืน** (`img/logo-3d-night.webp`) · ลุค C ทอง ไม่เอา
- รถในภาพ/แอนิเมชัน = **รถจากโลโก้เท่านั้น** (`brand/3d/truck-logo.glb`) ห้ามใช้โมเดลรถอื่น · สีรถไม่ฉูดฉาด

## ภาพ 3D (ผังสาขา)

- ปั้นเองเท่านั้น (ไม่ติดลิขสิทธิ์) · ไม่ใส่คน · โทนเดียวกันทุกสาขา
- ผังสมส่วนตามดาวเทียม แต่เส้นเรียบ ตรงแนว ไม่หยัก
- หมุด = แบบ D เหรียญลอย (`brand/3d/pins/`) · ห้ามซ้อนกัน · สีหมุดดู `--pin-*` ใน tokens.css
- มุมกล้องล็อก: มองจากหน้าตลาด

## ท่าทาง (แอนิเมชัน)

- นุ่มและสั้น: hover ยกขึ้น 2–3px + ขอบเป็นเขียว (0.2 วิ) · สลับธีม 0.3 วิ
- เลื่อนลงแล้วค่อยโผล่: จาง + ลอยขึ้น 24px (0.7 วิ) · ถ้าเครื่องตั้ง "ลดการเคลื่อนไหว" = โผล่ทันที
- เปลี่ยนสาขาบนผัง = **พลิกไล่ทีละช่อง (wave)**
- มือถือ: เลื่อนขึ้นลงอย่างเดียว ผังต้องไม่ย่อขยายเองตอนเลื่อน
